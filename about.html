关于「层叠之境」

🎯 建馆初衷

「层叠之境」是一个专注于中国史前聚落考古的线上数字平台。我们尝试用数字技术复原五千年前的村落空间，让普通人也能"走进"姜寨、良渚，理解古人如何选址、建房、共同生活。

项目的核心特色是"人口估算互动模型"——把考古学家写在论文里的计算方法，变成人人可以操作的在线工具。

🔧 技术架构

前端 HTML + CSS + JavaScript
地图 Leaflet + 高德地图底图
计算 JavaScript 原生计算
部署 GitHub Pages 静态托管
